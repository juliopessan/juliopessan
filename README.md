## Engineering principles

- **Business outcomes first.** Start with measurable operational problems, not agent count.
- **Human accountability.** Keep approvals, architectural decisions and risk ownership explicit.
- **Design for verification.** Document assumptions, failure modes, evaluation criteria and decision records.
- **Build for operations.** Treat security, observability, cost and maintainability as engineering requirements.
- **Reuse over reinvention.** Prefer repeatable patterns, skills, templates and delivery playbooks.
